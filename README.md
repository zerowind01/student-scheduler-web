# 学生排课工作台 (Student Scheduling Workbench Web App)

一个专为教务机构与老师打造的**Web端学生排课工作台**。核心优势是支持**拖拽学生姓名到周日历区域进行快速排课**、课时自动扣减、冲突自动检测与可视化管理。

---

## 🌟 核心功能亮点

1. **左侧学生名单 (Student Sidebar)**
   - **极简卡片展示**：展示学生姓名、科目、剩余课时、联系电话及专属配色。
   - **课时预警**：剩余课时 ≤ 2 节时自动高亮预警红框。
   - **快捷筛选**：支持“全部”、“课时预警”、“本周未排”三类视图及关键字实时搜索。
   - **原生 HTML5 拖拽**：鼠标按住学生卡片即可自由拖拽至日历中。

2. **右侧周日历视图 (Weekly Calendar View)**
   - **7天周视图**：显示周一至周日 08:00 - 21:00 精细时间轴（每小时 64px 高度，15分钟级精度）。
   - **拖拽放置 (Drag & Drop)**：
     - 从左侧学生列表拖拽学生到日历对应日期/时间格，松开鼠标即可自动弹出排课窗口并预填时间。
     - 拖拽已有课程卡片，可在日历网格间自由移动以快速调课。
   - **拖拽预警高亮**：鼠标悬停于日历列时，自动高亮拟排课时间区间并显示时间预览。
   - **冲突检测 (Conflict Warning)**：若同一时间段安排了重叠课程，卡片右侧红边闪烁提示。

3. **快捷数据管理 (Data Management)**
   - **自动持久化**：所有数据自动同步存储至浏览器 `localStorage`，刷新页面不丢失。
   - **演示数据一键恢复**：内置真实场景示例数据，方便开箱测试。
   - **数据导出**：支持一键导出包含学生与排课记录的 JSON 数据备份。

## 🚀 运行与使用方法

### 方式一：直接用浏览器打开（最快）
1. 在文件管理器中打开项目路径：
   `student_scheduler_web/index.html`
2. 双击 `index.html` 或将其拖入 Chrome / Edge / Safari / Firefox 浏览器中即可使用！

### 方式二：通过本地 Web 服务器运行
使用 Node.js / Python 启动静态服务器：

```bash
# 进入 Web 项目目录
cd student_scheduler_web

# 使用 Python 启动
python -m http.server 8080

# 或使用 Node.js npx serve
npx serve .
```

打开浏览器访问 `http://localhost:8080` 即可使用。

## 🔄 云同步部署说明

- 电脑端 / 手机端请通过 Netlify 部署后的网址访问（如 `https://zippy-meerkat-cfab1f.netlify.app`）
- 双方在设置里填同一个"同步码"即可实时同步（约 2 秒）
- 云端数据存储在 Upstash Redis，凭据由 Netlify 服务端函数持有，前端代码不含任何密钥
- 本地开发时直接双击 `index.html` 只能用本地存储，云同步功能不可用（会有提示）
